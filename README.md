# RE-Store

### Idea
This app is made to reconnect past memories to the present by utilizing ai image transformation to turn old faded images into modern day photos.
This can bridge the gap many have with their past memories by restoring their past to images of those close to them and storing them in one area

### Structure
- Frontend: Handles all visual display elements and communication with storage and backend
- Backend: Contacts ai models and can output the response to transformation requests from frontend
- Storage: Not Yet Added
